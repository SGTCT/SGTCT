# School of General Technical and Construction Trades — сайт

Главная страница школы. Чистый HTML/CSS/JS, без сборщиков и зависимостей — можно открыть
`index.html` прямо в браузере или разместить на GitHub Pages.

## Структура

```
index.html        — главная страница
css/style.css      — все стили
js/script.js        — вся логика (меню, анимации, форма)
images/             — сюда кладутся реальные фото (см. images/README.md)
```

## Как разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите в него все файлы этой папки
   (сохраняя структуру — `index.html` должен лежать в корне репозитория).
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/ (root)`.
4. Сохраните — через 1–2 минуты сайт будет доступен по адресу
   `https://ваш-логин.github.io/название-репозитория/`.

## Что доработать перед публикацией

- Заменить текстовые заглушки фотографий (`<div class="img-placeholder">`) на реальные `<img>` — см. `images/README.md`.
- Подключить обработку формы на странице «Контакты» (сейчас она просто показывает сообщение,
  без реальной отправки — понадобится сервис вроде Formspree, Getform или свой backend).
- Заменить телефон, email и адрес в разделах «Контакты» и в подвале на настоящие.
- Ссылки `#` у карточек программ и новостей сейчас никуда не ведут — под каждую программу
  нужно создать отдельную страницу (структура для неё уже согласована ранее) и проставить ссылки.
